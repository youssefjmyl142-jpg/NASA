# 🚀 Space Mission Design Game

مشروع مقدم لتحدي ناسا لتطبيقات الفضاء (NASA Space Apps Challenge) - **تحدي رقم 13**.

## 📌 عن المشروع
تطبيق ويب تفاعلي ومحاكي هندسي يضع اللاعب في دور مهندس فضائي لإدارة وتصميم بعثة متكاملة عبر الموازنة الدقيقة بين الميزانية، الكتلة، وتوليد الطاقة، مع التعامل مع أحداث الطوارئ كالعواصف الشمسية.

## 🛠️ التقنيات المستخدمة
* **HTML5:** الهيكل الأساسي للواجهات.
* **CSS3:** التصميم الحديث وتقنية زجاج الواجهات (Glassmorphism).
* **JavaScript (ES6):** إدارة منطق اللعبة وحسابات المحاكاة والأحداث الطارئة.

## 💻 طريقة التشغيل
1. تأكد من وجود الملفات (`index.html`, `style.css`, `script.js`) في نفس المجلد.
2. افتح مجلد المشروع باستخدام **Visual Studio Code**.
3. استخدم إضافة **Live Server** لفتح ملف `index.html` وتجربة اللعبة مباشرة على المتصفح.
